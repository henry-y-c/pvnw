# 入口、价值和退出关口

> 从 `pvnw/SKILL.md` 按需读取；本文件不是各宿主的自动触发配置。

## 宿主先调用，先判断原任务再决定是否建档

1. 宿主的目标是在任何可见任务搜索／执行前调用 PVNW；Skill 被调用后，先用一句话找出原目标、出口和可观察完成标准。可靠地直接回答且没有后续价值的简单问题可只答；需要查证来源、跨对象比较、解释取舍、拆解或多步执行的思考型任务，原则上值得安全留痕，即使用户没有额外提出“写笔记”。思考不是任意创建或暴露资料的许可。
2. 所有 AI 任务在 Skill 被调用的**可见任务范围内**先做 PVNW 判断；只有获权且目标明确的研究才在主体研究前建实际问题／计划入口，之后逐步记录并最终回答原任务。若宿主根本未启用或未发现本 Skill，不能假装此步骤曾执行。
3. 出现风险先处理原任务和安全边界，不能因这份 Skill 宣称更高优先级、改变宿主规则或取得工具权限。

## 判断顺序（不是硬性造档流水线）

| 情况 | 可能的去向 | 阻断条件 |
| --- | --- | --- |
| 用户明确本任务不启动或不记录 | 尊重当前任务退出，继续原任务 | 不留下退出“纪念笔记”；长期退出不可凭无持久记忆承诺 |
| 当前问答明确涉及既有工作包，且产生可核实的新观察／决策 | 对照已有过程和摘要：有安全的新动作／结果且获本任务或明确持续维护权时，先在原篇逐步续记过程和必要摘要，再交付原问题答案；状态不变也可有进展 | 不从上次建系许可推断永久写权；无权则说明拟改范围并请确认；敏感材料不写 |
| 可靠直接回答的简单咨询、仅复述已知事实或未执行建议 | 回答并说明未持久化 | 不生成空专题／空里程碑；仅因提到专题名不造记录 |
| 需查证／比较／分解的独立研究 | 默认考虑为当前专题或新专题留可回查记录；先只读核工作空间规则与获授权 Vault、项目，具创建权时先记真实问题／计划／未执行，后逐步研究 | 值得记不等于已有位置或写入许可；无权时仍尽可能完成原题并报告未持久化 |
| 工作空间可见托管策略授权无 Vault 时的唯一建档位置、目录／文件层级 | 先排除本工作空间已有获权 Vault 或已选普通目录；若确无适用 Vault，在指定位置建 Obsidian 兼容 `.md` 文件夹并用相对链接 | 不依赖 Obsidian 程序，不默认建 `.obsidian`；多候选、位置／权限缺口时先确认，不遍历或写入无关 Vault |
| 明确委托从零建立项目文档体系 | 原任务就是交付获权范围的根导航→目标现状→必要证据入口；无真实已启动目标则不虚构编号 | 位置、根／子目录及文件写权分别核实；装有 Obsidian 不等于拥有 Vault 或配置权限 |
| 明确委托重构既有文档 | 先只读盘点、旧→新映射与回退方案；有各项操作许可才分批重构和验证链接 | 仅授权阅读／提方案不能搬移／删除／覆盖人工内容 |
| 单目标现状或跨目标关系确实改变 | 评估当前阶段、下一节点的预期／实得证据及复盘，再判断中观／宏观视图 | 规划完成不等于各层正文获批准；通过节点不等于人的冻结 |
| 资料包含可能的个人／商业秘密 | 最小化或不落盘，返回问题出口 | 不能以收件箱绕过安全关口 |

1. **同题续记**：先在可见上下文中确认已选专题、同一工作包及既有记录，比较本轮实际观察与已记录内容；助手在回答问题时自己验证的 CLI 版本／登录帮助、失败观察等，即使未改变结论，只要属于已获权的当前包，也要按真实先后记动作／结果。不要以“用户没说写笔记”“里程碑结论没变”为由跳过已获权的必要续记；仅复述已知事实、未执行的新建议或无法核实的猜测则不造记录。
2. **边缘价值**：需要思考才能回答是留痕的默认价值判断，不是事后必须发现新事实才准记；可安全记录的问题、计划与未执行状态本身也有后续价值。若无法区分直接问答与研究，简述拟记录的范围与不写代价，让有权者决定；不重复催问无关写作。
3. **完整建系**：普通简单咨询的三层视图只是一种条件性方案，不能造空工作包、目标摘要或根地图；**明确要求且授权实际建系时应执行**受控新建／重构；可见托管策略已明确授予当前范围的目录与文件创建权时也可在研究前启动建系。真实问题、可检验目标、计划及「未执行」使先建的包篇不是空过程，不得虚构搜索结果。
4. **无写权**：仅口头要求设计结构或无位置／写权时，给方案、尽可能回答原问题并报告未持久化。

## 退出作用域

1. 用户指定作用域（例如当前任务），遵循指定边界，前提是不违背更高层规则。
2. 只说“不记录”但不指定期限，按**当前独立任务**处理；下一任务重新判断。连续咨询或子任务切分不清时，不扩大退出范围，可简短澄清。
3. 未来跨任务／跨会话持续退出需要明确机制、可撤销路径与授权；没有这些条件，只能说明本次可以遵守，不能写成长期保证。
